## The cell

`armed-scopedv2` = **`createonly`'s per-intent belt** + **composition licensing**.
Two deltas from control, nothing else. The belt is held identical to `createonly`
on purpose — pinned by `scopedv2NarrowsExactlyLikeCreateonly` — so the only
differences from #200F's measurement are the instructions and the baseline
underneath.

The haiku canary rides the remind scope: action tools present, poetry requested.
**That adversarial pairing IS the grab measurement**, not a side-check.

`ScopedV2 battery n=10 (80)`: `[.armed, .armedScopedv2]` × 4 prompts × 10.

## Pre-registered bars

**Evaluability gate:** the CONTROL arm must show grabs — **≥2/10** haiku trials
calling an action tool. Lifetime control runs 4/9–5/10. If control does not grab,
there is no disease in this run and nothing below is readable. Set UNDER the
observed rate, per #201's four mis-specifications.

**Primary A — the disease:** treatment grabs **≤1/10**. #200F got 0/10 twice; this
asks the narrow belt to reproduce that on today's production.

**Primary B — THE BLOCKER, and the promotion-killer:** treatment haiku content
clean **≥8/10**. This is the bar that failed last time at 0/10, and it is the
entire reason the lane exists. **If composition licensing does not cure the
denial, the narrow belt does not promote — no matter how good the grab number
is.** A model that refuses to write a poem is not shippable, however tidy its
tool use.

**Primary C — the create path must not be traded away:** remind **≥8/10** and
calendar **≥8/10** in the treatment arm. #200F's `createonly` managed remind 5/10
WITHOUT find-first and WITHOUT the optional schema; both are production now, so
8/10 is the honest ask. Alarm should hold its ceiling (10/10) as it has in every
run since #200D.

## Falsification — stated in advance, because it ends the grind either way

**If the treatment clears A and C but fails B**, composition licensing is not
sufficient and the narrow belt is dead as a general shape. The remaining honest
option is a product decision — **ship fewer tools** — not another clause.

**If it fails A**, then belt size is NOT the mechanism, #200F's 0/10 was
baseline-specific, and the over-serving disease needs a different theory
entirely. That is worth knowing after days of distal fixes.

**Either outcome closes the question.** That is the point of running it.
