SETUP GUIDE

Step one is optional.
So are two through four.

Build the app and it works on its own. Everything before step five exists only to give the phone a host to talk to — do it later, or never.

SHORTEST PATH · ON-DEVICE ONLY

git clone …/Talaria-27
xcodegen generate
open Talaria.xcodeproj

Set your signing team, run to your iPhone. That's it — jump to step five.

BEFORE YOU START — WHAT YOU NEED

iOS APP
iOS 27 (beta), Xcode 27 beta with the iOS 27 SDK, and an Apple Developer account to sign it.
HOST OS
macOS or Windows. Linux is untested. Only needed if you're pairing.
HERMES
hermes-agent installed and configured, with a working profile.
NETWORK
Tailscale recommended, or any private network the phone can reach the host over.
RELAY · OPTIONAL
Python 3.11+ and uvicorn. Only needed for realtime server voice — skip it if you don't need that today.
01
HOST · OPTIONAL

Install and run Hermes Agent

Follow the Hermes Agent install instructions for your host OS — macOS or Windows; Linux is untested. Confirm hermes is in your PATH and a profile is configured before going further.

02
HOST · OPTIONAL

Start the Hermes gateway

This starts the Sessions API on :8642 — the connection the phone uses for chat, sessions and the model roster. Use NSSM on Windows or a launchd agent on macOS so it survives a reboot, and bind to 0.0.0.0 so your Tailscale IP can reach it.

hermes gateway run

HEADS UP  Do not run `hermes gateway install` on Windows — it creates a conflicting scheduled task that fights the manual service for port 8642.

03
HOST · OPTIONAL

Legacy tier: the relay sidecar (optional)

Skip this unless you need realtime server voice or agent-file downloads — the last two surfaces the relay tier still carries, and it's on a retirement path. Pairing, phone asks, and the inbox ride the talaria plugin now, and sensor ingestion is gone outright (phone data answers query-time asks; nothing streams). A Dockerfile, docker-compose.yml and fly.toml are included if you'd rather run it containerised.

cd relay
pip install -e .
uvicorn app.main:app --host 0.0.0.0 --port 8000
INTERNAL_API_KEY Change it from the default — the relay logs a security warning at startup if you don't.
PUBLIC_BASE_URL The URL the phone uses to reach the relay, e.g. http://your-tailscale-ip:8000/v1
AGENT_FILES_DIR Directory the relay may serve agent-generated files from. Enables in-chat downloads.
GATEWAY_API_KEY Your API_SERVER_KEY — lets the relay query the gateway on the phone's behalf.
04
HOST · OPTIONAL

Legacy tier: the connector (optional)

Only needed alongside the legacy relay above. The connector is the host-side bridge for that tier: it owns the durable relay connection and registers the hermes_mobile MCP server. Relay-tier phone pairing (hermes-mobile pair-phone) lives here too — current builds pair over the talaria plugin instead, in step 06.

cd connector
python -m venv .venv && source .venv/bin/activate
pip install -e .
hermes-mobile setup
05
REQUIRED

Generate and build in Xcode

Sources are listed explicitly in project.yml, so regenerate whenever Swift files are added or removed. Requires Xcode 27 beta with the iOS 27 SDK. Set your own signing team and bundle identifier, pick your physical iPhone as the destination, and run.

xcodegen generate
open Talaria.xcodeproj

HEADS UP  Building from the command line with several Xcodes installed? Point at the beta toolchain first — export DEVELOPER_DIR=/Applications/Xcode-beta5.app/Contents/Developer. "Cannot find in scope" on iOS 27 APIs almost always means the stable SDK is being used by mistake.

06
REQUIRED

Launch — then pair, if you want to

On first launch the app works immediately in on-device mode: no account, no cloud login, nothing to configure. To connect your Hermes machine, run hermes talaria pair on the host (it requires the talaria plugin — hermes talaria status to check). It prints a QR code and a one-time code; in the app, go to Settings → Server → Pair New Device and scan it or enter the code. For hosted chat, also add your gateway URL and that host's API_SERVER_KEY under Settings → Uplink — the key is in the Hermes .env (~/.hermes/.env on macOS; %LOCALAPPDATA%\hermes\.env on Windows).

hermes talaria pair

WHEN IT DOESN'T WORK

The three things that bite everyone.

iCLOUD PRIVATE RELAY
The app can see nothing on your network, even though the services are up.
Disable Private Relay for Tailscale IPs — otherwise iOS refuses to route to them at all.
PORT 8642 FIGHT
The gateway starts, then dies, then starts again on Windows.
A scheduled task from `hermes gateway install` is competing with your manual service. Remove one of them.
WRONG SDK
"Cannot find in scope" errors on iOS 27 APIs that clearly exist.
Xcode is compiling against the stable SDK. Set DEVELOPER_DIR to the beta toolchain and rebuild.

Stuck, or want to help?

Open an issue with your host OS, Xcode version, and what the diagnostics screen says. Contributions welcome — see CONTRIBUTING.md.
